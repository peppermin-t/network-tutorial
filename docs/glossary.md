# Glossary

- Address: identifier for an endpoint or interface at a layer.
- ALPN: TLS extension for negotiating application protocol.
- ARP: local IPv4 IP-to-MAC resolution.
- Backpressure: rejecting or slowing callers when capacity is exhausted.
- Broadcast address: last IPv4 address in many subnets.
- CIDR: prefix notation for network size, such as `/24`.
- CNAME: DNS alias record.
- Connection refused: TCP endpoint replied that no listener accepted the port.
- Container port: port inside a container namespace.
- Default route: fallback route when no specific route matches.
- DHCP: protocol for automatic IP configuration.
- DNS: name-to-record resolution system.
- DNS server: resolver endpoint that answers DNS queries.
- Firewall/security group: policy controlling allowed traffic.
- Forward proxy: proxy selected by a client to reach external destinations.
- Gateway: next hop or application intermediary, depending on context.
- Host port: port published on the host machine for container access.
- HTTP: request/response application protocol.
- ICMP: control protocol used by ping and other diagnostics.
- IP address: network-layer address.
- Keep-alive: reuse of a connection for multiple HTTP requests.
- NAT: address/port rewriting between networks.
- Network address: first address representing a subnet.
- NXDOMAIN: DNS response saying the name does not exist.
- Port forwarding: inbound mapping from external port to internal host/port.
- Private IP: address intended for private networks.
- Proxy buffering: proxy holds upstream response before forwarding.
- Reverse proxy: gateway receiving client requests and forwarding to upstreams.
- RPC: remote procedure call pattern.
- Route table: rules used to choose next hop/interface.
- SNI: TLS hostname indication sent during handshake.
- Socket: OS API endpoint for network communication.
- Static IP: manually planned stable address.
- Subnet mask: bit mask defining network portion of an address.
- TCP: reliable ordered byte stream transport.
- Timeout: deadline for a network operation.
- TLS: encrypted session protocol used by HTTPS.
- Traceroute: path-shape diagnostic using TTL behavior.
- UDP: connectionless datagram transport.
- VPN: virtual interface plus route/DNS policy plus encrypted tunnel.
- WebSocket: long-lived bidirectional message channel.
