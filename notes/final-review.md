- I can explain HTTP/1.1 request/response parsing.
- I can reason about proxy timeout/retry behavior.

- I can explain RPC and WebSocket communication patterns.
- I can debug basic Docker service-name and port-mapping issues.
- I can explain how concurrency limits, queueing, 429 responses, and retry storms affect distributed service stability.
- I can map local model serving symptoms such as slow first token, long streaming responses, and client cancellation back to the same network path.
